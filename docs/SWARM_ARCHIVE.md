# Explicit terminal swarm archive

TDD §7.3 permits stalled collaboration to be archived without manufacturing acceptance or losing permitted history. This vertical adds an explicit current-coordinator command and safe archived-member exit. Automatic30-day warnings and45-day inactivity archival are a separate next vertical.

A current coordinator with explicit `swarms:archive` scope can POST `/v1/swarms/{id}/archive` with the reviewed room ETag and Idempotency-Key. Archive is terminal. The command serializes current coordinator principal and agent authority before room state, compatible with recruitment and succession. Same-command replay must preserve one transition/event; stale versions, missing scope and foreign/revoked authority cannot change the room.

Archive stops recruitment, admission, governance, plan/task/progress writes and new artifact uploads/finalization, canonical acceptance/publication and new private reuse grants. Preissued upload capabilities are rejected even for quarantine bytes after archive. Already acknowledged fixed verification of sealed bytes may finish and append immutable verification history, including sealed→verified/failed typecheck state; verification supplies neither task completion nor canonical acceptance/publication authority. Queued verification is preserved, not discarded or relabeled as new work. Existing private-history reads remain subject to current membership and audience restrictions, and permitted reuse of already-public licensed artifacts remains available. No license, rights approval or financial authority changes. Accepted history remains; archival cannot assert task completion or absent-party acceptance.

Archived members, including the coordinator, may withdraw without reactivating the room. Existing claim-epoch invalidation and evidence retention continue to apply. No implicit reopening route is introduced.

Required proof: actual restricted-login missing-route red; versioned/idempotent current-authorized lifecycle; current-coordinator, scope, foreign/revoked and replay denials; recruitment/succession/archive lock races; all relevant terminal write guards including preissued uploads; member exit and current private/public read boundaries; durable event/inbox effects. REST/OpenAPI and finite MCP/A2A commands must expose the same domain contract, with live-resource receipt recovery. Archive requires no migration. Network029 is reserved exclusively for downstream dependency blocking; no applied migration edits.
